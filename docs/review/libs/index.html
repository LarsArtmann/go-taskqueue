03Cross-cutting findings

Version currency: fully closed

All 9 adopted libraries (plus the server_timing trial) sit on their newest tag as of 2026-11-11. The go-cqrs-lite four-module wave landed 2026-11-09 (commit d315904f) — metaengine v4.23.0, sqliteengine v4.8.0, system v4.18.0 with the AggregateFn SQL-injection hardening, id v4.7.5. Newest upstream movement not yet consumed: cqrs-htmx loginpage/v4.18.0 and cmdguard v5.1.0 (2026-11-11) — neither touches a keep-out verdict. One observation, NOT landed: an uncommitted local edit renames the queue facade shims to v5 while upstream has no queue/v5 tag (see the go-cqrs-lite report's refresh note).

The remaining distance is deliberate, not neglect

go-error-family (21), go-retry (78) and go-health (41) each hold a small, named seam: the hand-rolled prober exists because upstream's classifier cannot express tq's per-check warns (the PROPOSED severity-override design doc names go-taskqueue), and the options tail / WrapOnce leftovers are polish rows, not adoption gaps. Their recommendations stay surgical: store-busy classifier, UTF-8/no-cache in writeHealthJSON, DurationNanos, options tail.

The not-invented-here boundaries held — with one sanctioned exception

Every KEEP OUT cites an ADR or a test-pinned existing seam: internal/retryx, runactor, the stdlib-flag CLI, journal DedupKey, the no-store API posture. The one boundary that moved did so through the sanctioned door: server_timing, graded WORTH A TRIAL on 11-08, was mounted behind the existing RequestLog flag on 11-09 with a pinned gate test — and its own report now carries the never-unconditional gate note (Server-Timing on a token API is a performance oracle). No rejected library was found to already have a hand-rolled duplicate that should have been the library all along.

Two prior deep-dives superseded

docs/research/2026-10-05_go-cqrs-lite-metaengine-system-deep-dive.html and docs/research/2026-09-14_templ-components-deep-dive.html are superseded by go-cqrs-lite.md and templ-components.md (narrower + newer wins). templ-components moved 64→78 since September; every high-impact cqrs-lite gap from October has since landed.
