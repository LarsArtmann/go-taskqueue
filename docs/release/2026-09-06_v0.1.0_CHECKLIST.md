## Owner decisions (made for this release)

- **Squash before tag: NO.** History ships as-is. The granular commits carry
  the auto-daemon bookkeeping plus real per-feature commits; squashing would
  rewrite nothing of value and destroy the audit trail of parallel sessions.
  Decision recorded here per the round-2 plan (D14); revisit only if a future
  owner wants curated history.
- **v0.x = pre-release on GitHub:** per Go release practice, the v0.1.0
  GitHub Release is marked `--prerelease`; SemVer 0.x already signals
  instability to `go get` consumers.
