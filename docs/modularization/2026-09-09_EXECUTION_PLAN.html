go-taskqueue Modularization — Execution Plan

Seven steps, one commit each, leaves the tree green after every step. Strategy per 2026-09-09_PROPOSAL.html: replace-directives only, paths unchanged, shared tags (root + subdirectory) at release time. Working branch: master (repo convention under concurrent agents); every step is a revertable checkpoint.

Standard gate (every step)

go build ./... && go vet ./... && go test ./... -count=1 -race -timeout 120s
# plus, for the module created in this step:
cd internal/<mod> && GOWORK=off go build ./... && go vet ./... && go test ./... -count=1 && go mod tidy && git diff --exit-code go.mod go.sum

Tier 3

Step 6 — CI, nix, fuzz, bootstrap wiring

(a) scripts/ci-local.sh: per-module GOWORK=off build/vet/test loop, GOOS=windows cross build/vet per module, replace-portability audit (no absolute paths), v0.0.0-pin audit (test-aware), advisory golangci loop extended to the five dirs. (e) bootstrap .tq-verify template made module-aware for dogfooding.

Step 7 — docs & final reflection

ADR-0011 (module split decision), AGENTS.md (commands, architecture table, store invariants note), proposal cross-check. Verify: everything above + docs consistency.
Rollback: revert docs commit only.

Standalone verification battery (after step 7)

# 1. workspace-less root build
go build ./... && go vet ./... && go test ./... -count=1 -race
# 2. per-module isolation (the FM#12 gate)
for m in task journal queue executor worker; do
  ( cd internal/$m && GOWORK=off go build ./... && GOWORK=off go vet ./... && GOWORK=off go test ./... -count=1 ) || exit 1
done
# 3. hygiene
grep -rnE 'replace .*=.*=> */' --include=go.mod . && exit 1   # no absolute replaces
go mod verify
# 4. reproducible build
nix build
