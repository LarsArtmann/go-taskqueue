## e) WHAT WE SHOULD IMPROVE

1. **Negative-control design rule**: copy-and-rerun-the-script controls
   MUST assert the mutation applied (cmp/diff) BEFORE rerunning the copy;
   a no-op mutation makes the copy pass its own test and recurse.
   Stub/seam injection (check-gosec's canned binaries) avoids the class
   entirely — worth preferring as the default shape.
2. **Self-referential extraction hygiene**: any script that sed-extracts
   its own bytes for a self-test must anchor patterns so the extractor's
   own source cannot match (line-start anchors, or extract from a range
   the self-test code cannot share).
3. **Daemon-race surface shrinks with smaller uncommitted spans**: stage +
   commit at the item's own gate (05-19 §e5 said it; this session proved
   it twice more — both folds were multi-edit spans left dirty while I
   iterated on the next fix).
