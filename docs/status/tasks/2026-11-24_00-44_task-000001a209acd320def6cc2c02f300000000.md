## e) WHAT WE SHOULD IMPROVE

1. **Make the amend fallback atomic.** The rule "amend once the stat proves it mine" is
   stateless across tool calls. Either a one-command wrapper (`scripts/amend-mine.sh <id>`:
   assert HEAD content matches the expected fileset, then amend, in a single bash
   invocation) or a convention line mandating the stat+amend in one chained command.
   (rowed, item 1)
2. **A hook seam without a default-path battery is a coverage lie.** My original commit
   shipped four batteries that ALL rode the `TQ_PROXY_PROBE_CMD` hook and never executed
   `default_probe` — the reviewer's finding was invisible to the self-test by construction.
   Convention candidate for AGENTS §Conventions: when a gate gains an override hook, the
   same commit must add a battery through the DEFAULT path (or document why it cannot).
   (rowed, item 2)
3. **Session-shell heredoc hazard needs a Known Issues line** (with the AGENTS size-budget
   reset in the same change): quoted heredocs inside `$( )` with shell metacharacters fail
   to parse; multi-line commit messages go through `git commit -F <file>`. (rowed, item 3)
4. **The commit-theft row's evidence should be annotated** (twice → three times live, this
   session being the third, with the heal shape that worked). Existing row — annotation, not
   a new mint; its owner ruling (auto-chain vs advise-only) is still pending.
5. **The heal+revert+reapply dance is expensive under concurrency.** The attribution gate
   flags a footer-less mechanical revert in the span (correctly — it caught mine). A
   convention that heal-created reverts carry the heal ticket's footer upfront (as I
   retro-fitted) would remove one gate round-trip from every future incident of this shape.
