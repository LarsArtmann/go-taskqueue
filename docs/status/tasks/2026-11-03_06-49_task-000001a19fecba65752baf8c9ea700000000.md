## e) WHAT WE SHOULD IMPROVE

1. **commit-task.sh has a race window against the daemon** (d1 sweep 2):
   between the script's file existence check and its `git commit`, a
   sweep can take the named files, and the script commits the remainder
   silently. A post-commit verification (each named file diff-vs-HEAD)
   failing loudly would convert the silent split into a caught error.
2. **eq()'s failure message omits the header name** (d2): passing a
   label (or wrapping contentType with a header-name-aware closure)
   makes negative-path assertions robust and failures human-readable.
3. **Census regexes over quoted literals must allow spaces and carry a
   no-match sentinel** (d3): the `len(pinMedia)==0` Fatal covers empty;
   the space-class bug is the general lesson — write the regex against
   the OBSERVED literal shapes, not a guessed token class.
4. **heal-daemon-sweep.sh default range**: print the computed range in
   the tag-refusal message and/or narrow the default walk (d5).
5. **root-gate receipt gap** (already queued as a TODO row): the gate
   emits go-test `ok  pkg` lines, so the `grep -c '^ok:'` convention
   counts 0 on green — normalize the summary or document the per-gate
   recipe (`^ok ` + FAILs).
6. **Evidence archival**: gate logs cited in reports should go through
   `scripts/archive-evidence.sh` (or an explicit keeper dir), not /tmp.
7. **The 06-49 report was written once, then expanded** (this rewrite):
   checkpoint-early + amend would have avoided a second report-shaped
   commit in the history. Same lesson as d4.
8. **gofumpt/golines advisory warns on headermatrix_test.go are
   pre-existing** (file was already flagged before this session's

   churn-only; queued low priority.
9. **The doc-parity census pattern generalizes** to other matrix cells,
