## e) WHAT WE SHOULD IMPROVE

1. **The field-shift bug class generalizes**: `// ""` → `@tsv` → `IFS read` is a
   pattern, not a one-off. Any `read` split of a tsv whose FIRST field can be empty
   silently shifts every field. check-ci was the only @tsv consumer in scripts/
   today (grep-verified), but Go code or future scripts can reintroduce it — the
   lesson is "null-coalesce to a non-empty sentinel at the jq boundary", not
   "fix check-ci".

   original `classify_conclusion` self-test passed while the merge-base branch

   exercise a refactored function through the same entry the live path uses are
   the only pins that survive refactors; `red_branch_relation`'s optional `-C`
