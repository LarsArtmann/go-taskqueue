## e) WHAT WE SHOULD IMPROVE

1. **Commit-first discipline needs to be mechanical**: write the change,
   IMMEDIATELY `git add <files> && git commit` with the footer, THEN run
   gates. Never hold a dirty tree across a tool invocation.
2. **Amend-with-dirty-index is a loaded gun**: pathspec commits silently
   exclude forgotten files and amend silently includes staged strangers.
   A pre-commit `git diff --cached --name-only` eyeball is the cheap guard.

   contains ANY commit whose files I didn't author, prefer leaving the
   daemon chores in place and minting a corrective footered commit, or

   GOCACHE override + PATH override + GOWORK scratch are all documented in
