   CONTRIBUTING.md CLAUDE.md` belongs in the FIRST tool batch of every
   dispatch, before anything else. Seven consecutive misses is not a
   memory problem; it is a checklist problem.

   redirect + `echo EXIT=$?`, grep counts read from the file afterward.
   Make it the reflex; the index documents the genus six times.
3. **Env hygiene for go commands**: GOEXPERIMENT=jsonv2 goes INLINE into
   every bash call that runs go — including `cd`-into-module runs —
   never via cross-call state.
4. **Close-out gates for doc/TODO edits belong in the WORK turn**:
   `check-todo-list.sh` + `check-doc-refs.sh` +
   `TestRepoTodoListParses` whenever TODO_LIST.md or docs change.
5. **Pin Go-side contracts with tests, not prose**: the adoption guard
   is template-call-scoped by design, so any adoption that lives in a
   Go props builder (SEO.NoIndex today; HeadContent/Footer/ThemeColor
   already) has zero test backstop. A small table-driven props test
   closes the class, not just this instance.
6. **Probe hygiene stays single-chain** (create+run+trash in one call);
   the daemon race (§d4) is minimized, not removed — /tmp-based
   GOFILE tricks don't work for in-package tests, so the chain is the
   best available control.

   BEFORE staging anything new catches daemon folds; amend beats
   rebase for unpushed footerless folds (worked exactly as 02-19 §e
