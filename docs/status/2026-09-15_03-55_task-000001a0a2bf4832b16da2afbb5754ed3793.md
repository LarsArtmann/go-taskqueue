## e) WHAT WE SHOULD IMPROVE

1. The review loop has no structural termination bound when a reviewer keeps
   rejecting fixes — dedup is per (review-id, finding-title), so every new
   review mints a new fix. A max-reviews-per-root-task knob (like dlqfix's
   "no second autopsy") would make the loop bounded by construction.
2. `tq facts --json` is indented; grep-based smokes should use a
   compact-mode flag or jq-style extraction instead of whitespace-fragile
   `grep -o` patterns (three assertions needed `: *` hacks).
3. The stub-agent discrimination problem (fix review quotes the original
   prompt) is a sharp edge every future review smoke will rediscover; the
   fix prompt could carry a machine-greppable marker line.
4. `tq doctor` fails hard outside the jsonv2 env — smokes must export
   GOEXPERIMENT=jsonv2 just to use doctor as a liveness check; the ENV-LIE
   probe could degrade to WARN in smoke contexts.
5. Mint-time done-check (re-dispatch of DONE rows keeps costing paid laps —
   this row sat unchecked while multiple earlier reports list "reviews.sh
   e2e" as next work; the work existed only as a TODO row, but the re-
   dispatch pattern recurs across tasks).
