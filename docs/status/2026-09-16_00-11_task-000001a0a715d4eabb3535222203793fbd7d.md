**Verdict:** SHIPPED — small, complete, verified at root-module depth. One rule violation to disclose (§d1) and one judgment call to ratify (§g1).

The work item: `internal/webui`'s CSRF write-lockout tracker (`writeRateLimiter`) pruned a
client's strikes only when that same client contacted a write route again
(`pruneLocked`, per-contact). A source rotating IPs never re-contacts its own
key, so each forged source added a map entry that lived forever — unbounded
memory growth on the two write routes. This closes that.

## e) WHAT WE SHOULD IMPROVE

1. **Eviction is O(n²) worst case** (full-map scan per eviction; pathological
   all-locked 1024-entry map ≈ 500k comparisons, once, under mutex). Fine at
   this cap; switch to sort-once-evict-head if maxKeys ever grows.
2. **The bound is silent.** An eviction firing under legitimate traffic means
   a surprise key population (big NAT/proxy pool, or an attack) — a one-time
   `slog.Warn` on first eviction would surface it. Not added (smallest
   change), high value per line.
3. **Two clocks in one limiter.** `nowFunc` is injected for tests but the 429
   path computes `Retry-After` via hardcoded `time.Until` — formatting only,
   no behavior impact, but the wart will bite whoever tests the header value.
   (Row 89's "HTTP-date Retry-After fixture" will hit this exact spot.)
4. **maxKeys is test-tunable but not operator-tunable.** Right for now
   (loopback/one-proxy reality, documented on `remoteHost`); revisit only
   with a real deployment that needs it (§g2).
5. **Per-key in-process maps elsewhere.** AGENTS.md lists `rateLimitGates`
   (bounded by repo count — fine) and `closeoutPending` (task-ID-keyed,
   registered on 429-during-closeout). The latter's lifetime on CANCELLED
   tasks is un-audited; if a task dies cancelled while parked there, does the
   entry leak until process restart? Not researched (scope); flagged as a
   focused pass (§f item 7).
6. **The close-out itself:** this report indexes cleanly (row added below),
   cites its gates, and refuses padding — matching the conventions the
   2026-09-15 close-outs settled.
