## d) TOTALLY FUCKED UP

1. **Near-miss, caught by inches: the archive almost shipped as a ghost.**
   Sequence: I copied 16 `.log` files into a repo whose .gitignore carries a
   global `*.log` rule → git ignored all 16 → the auto-commit daemon committed
   only README + TODO_LIST (`1d925e5`, "2 changed file(s)") → `git status
   --short` reported a **clean tree**. At that instant the repo contained a
   README asserting the logs were archived while 16 of 19 archive files were
   invisible to git — a fabrication-grade artifact, committed by the daemon,
   indistinguishable from done. It was caught only because I read `git show
   --stat` on the daemon's commit instead of trusting the clean status.
   Self-criticism: `git check-ignore` on the target paths should have been
   step ONE of any copy-into-repo operation; my order was lucky, not
   systematic. The daemon + ignore rules + "clean tree" status form a
   silent-loss triangle nobody has written down until now.

   exit code failed to surface (`${PIPESTATUS}` empty under mvdan/sh) — exactly
   the pipeline-masking pattern AGENTS.md warns about. Re-ran unmasked (exit 0,

## e) WHAT WE SHOULD IMPROVE

1. **Check ignore-status before copying anything into the repo.** For any
   archive/evidence task: `git check-ignore -v <targets>` first, `cp` second.
   One command would have surfaced the `*.log` trap immediately.
2. **Never equate a clean `git status` with "the archive is complete"** while
   the auto-commit daemon is live: diff the daemon commit's `--stat` against
   the intended file set. The daemon turns silent ignores into clean-looking
   commits.
3. **Treat /tmp-referenced TODO items as hot (hours), not "before reboot".**
   f9's framing gave false comfort; the evidence died to an ordinary cleanup.
   Harvest-time could flag items whose payload references /tmp paths as
   same-session-priority.
4. **Evidence archives should ship with a SHA256SUMS manifest**, and a cheap
   CI check should assert every `docs/status/assets/*/README.md`'s promised
   files are tracked. Both together close the ghost-archive class permanently.
5. **Archive discoverability should ride existing reports, not closed TODO
   lines** — closed items scroll away; the 01-55 ANNOTATE pass (f5) is the
   right vehicle and should mention the archive path.
