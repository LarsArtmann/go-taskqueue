   commit template mandates attribution AFTER the footer, the repo
   mandates the footer LAST. Every window using the template
   reproduces (d1). The fix is mechanical: either the template
   embeds the attribution INSIDE the same paragraph as the footer
   (trailer parser accepts co-trailers) or the queue's scanner falls
   back to a body-wide regex. Until then every template commit is
   invisible to derivation.
