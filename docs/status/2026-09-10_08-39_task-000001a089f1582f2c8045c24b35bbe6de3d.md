## Context

The wrapcheck/varnamelen lint-triage task (000001a089c3, commit `eaf73a9`) renamed
`q` → `query` inside `parseFilter` and the rename leaked into the string literal:
`r.URL.Query().Get("q")` became `query.Get("query")`. Emitters (search box
`name="q"`, `filterHref` writing `q=%s&`) were unchanged, so the dashboard text
filter and view-toggle query scope were silently dead while all tests stayed
green — no test pinned the parse side. Reviewer filed exactly one high finding;
this task fixed exactly that, nothing else.

## d) TOTALLY FUCKED UP (honest accounting of the _original_ sin)

- **The rename that caused this was mine (earlier task, `eaf73a9`):** a
  mechanical varnamelen rename touched a string literal because `q` (variable)
  and `"q"` (param name) look like the same thing. Rule for the future:
  **variable renames must never silently change string literals** — any `q`
  → `query` rename adjacent to `Get("q")` needs the literal checked explicitly.
- **The test gap was systemic, not accidental:** `board_test.go` pinned the
  _emit_ side (`viewToggleHref` → `/?...&q=sh`) but nothing pinned the _parse_
  side. Green tests + broken user-facing feature = the classic
  untested-boundary failure. Fixed now, but it took a reviewer to catch it.

## e) WHAT WE SHOULD IMPROVE

1. **Round-trip tests as the default for URL/state contracts.** Anything with
   a `parseX`/`renderX` pair should have a property-style round-trip test;
   it would have caught this bug at the first `go test` run.
2. **Rename hygiene rule in AGENTS.md** — when renaming a variable whose name
   matches a string literal used nearby (query params, JSON tags, map keys),
   grep for the literal before and after. Worth one AGENTS.md line.
3. **Test the boundary, not the halves.** Emit-only pins give false
   confidence; always pair with a parse-side assertion (or a single
   end-to-end request through the handler).
4. **Lint-triage tasks should diff-audit string literals.** A cheap
   `git diff | grep '"'` scan over renames touching `Query().Get`/JSON tags.
