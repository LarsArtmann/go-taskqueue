## What shipped

1. **`cmd/tq/crush.go` — `tq crush [flags] [crush args...]`**: wraps a crush
   session as close-out trigger #2. The child runs with INHERITED stdio (the
   operator sees everything live, interactivity preserved) while the wrapper
   tees both streams into a buffer; on child exit — clean OR crashed — the
   same replay-safe `tq session close` runs, so the close-out survives even
   when neither the PreToolUse registry hook (trigger #1) nor crush #3146
   SessionEnd (trigger #3) is available.

2. **Session id resolution, most-explicit wins**: `--id` flag >
   `$CRUSH_SESSION_ID` > `executor.ExtractSessionID` over the child's teed
   output (the line-anchored `session_id:` line or the verbose `INFO Created
   session …` marker — the same extractors the agent executor uses). No id
   found → an honest note on stderr, nothing closed, NO database opened
   (pinned by test).

3. **Shared close flow**: `runSessionClose` extracted from `tq session
   close` (cmd/tq/session.go) — the wrapper and the explicit close now run
   byte-identical attribution + mint + print logic; wrapper flags mirror the
   close flags (`--repo --project --summary --allow-dirty --db`) plus
   `--bin` (crush binary override; the test seam, same idea as the agent
   executor's stub-binary field).

4. **Exit-code honesty**: the wrapper's status IS the crush session's status
   — the child's exit code is preserved through `os.Exit` after the close
   flow has run (the close runs even on a crashed child; a crashed session
   is exactly the one whose close-out you cannot afford to skip). Tests
   exercise `crushRun` (streams injected, no os.Exit), cmdCrush is the thin
   exit-passthrough shell.

5. **Signal forwarding**: SIGINT/SIGTERM are relayed to the child so a
   Ctrl-C aimed at the wrapper still lets crush shut down cleanly; the close
   then runs off the completed wait.

6. **`cmd/tq/main.go`**: `crush` registered in the dispatch map + usage text
   (the parenthesized-identifier help-text class is not at risk: no
   Go-identifier leak).
