## e) WHAT WE SHOULD IMPROVE

1. Commit BEFORE running long verification when the daemon is live; amend
   only fails verification, never races it.
2. Test gates in isolation (one command in a scratch dir), not by watching
   a full ci-local run that takes minutes to reach the step.
3. The gate-vs-advisory boundary in ci-local is now three different
   treatments in adjacent steps (config verify = gate, lint = advisory,
   baseline growth = gate) — a comment block mapping these explicitly would
   prevent someone "fixing" the config-verify step into the advisory block.
4. Mirror the gate into ci.yml (see b1) so master CI catches it too.
5. The daemon's heuristic commits keep stripping Task-Queue-ID footers from
   queue-attributed work; every task pays the amend tax. A daemon that
   detects (or is told) it is racing an explicit task commit would remove a
   recurring footgun.
