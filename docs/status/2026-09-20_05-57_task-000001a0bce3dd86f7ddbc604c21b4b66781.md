   not process.** My mechanical repointer replaced EVERY dead token including

   `d035911`", the sanctioned :408 fork note). I only noticed because I

   be diff-archaeology against `216991f^`. If I had stopped one step earlier,
   falsified heal-forensics would be on master.

   sharing subject+author-date with a real commit (1537fd2/c888be6 → 9aaa7fc,
   4a28269 → e2e3f2e, 5d93115 → d035911) mapped to a DIFFERENT commit's twin.
   The collision audit caught them (same twin hit by two dead SHAs), but that
   detector only works when two dead commits collide on one twin — a lone
   mis-map is invisible to it. Reverted to baseline and documented, but the
   gate does not distinguish "honest no-twin residue" from "wrong-twin
   repointed"; a citation I repointed in the 214 could still be wrong.

## e) WHAT WE SHOULD IMPROVE

1. **Semantic site classification before any bulk SHA rewrite.** EVIDENCE
   cites (repot to twin) vs DEAD-CONTEXT prose (keep dead SHA, baseline it).
   A regex for the dead-context vocabulary (survived / abandoned / replaced /
   NOT reachable / over / backup / pre-rewrite / sanctioned / fork) would
   have been a 10-line pre-flight and zero falsifications.
2. **Gate upgrade: distinguish baselined CLASSES.** The baseline header
   documents the classes, but the gate treats all 28 identically. A
   per-line class tag (comment-suffixed) would let ci-local report residue
   shrink per class and keep the fork-note pair visible.
3. **Spot-check protocol for signature-matched twins.** N random maps per
   stage, human-readable old-vs-new table, before trusting a bulk repoint.
4. **Commit the resolver.** The staged matcher is ~80 lines of Python; as
   `scripts/dead-sha-resolve.py` (with --dry-run and the site classifier)
   the residue pass becomes reproducible instead of archaeology.
5. Same-class lesson as AGENTS.md's "tool output can lie": my own intermediate
   artifacts can lie too — the line-count sanity check that caught the
   duplicated map should be a default assertion in any mapping script, not a
   lucky `wc -l`.
